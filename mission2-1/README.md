# codyssey-ai-native-c2-mission2-1

# Codyssey 랜딩 페이지 기획서

코디세이(Codyssey) AI 네이티브 과정 미션 2-1의 결과물입니다. AI와 질의응답을 통해 랜딩 페이지를 기획하고, 기획서(`기획서.md`) 1개로 제출합니다. HTML 구현은 후속 미션(mission2-2)에서 진행합니다.

## 미션 취지

HTML 페이지를 제작하기 전에 방문자가 가장 먼저 확인할 내용과 필요한 기능을 구체적으로 정해 AI에게 전달하는 기획 과정을 실습합니다. 구현하지 않을 기능과 결과를 확인할 기준도 미리 정하고, 기획서를 작성해 AI 지시 문서이자 결과 검토 기준으로 활용합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `기획서_양식.md` | 기획서 작성용 빈 양식 (제공된 샘플) |
| `기획서.md` | 미션 2-1 결과물. 대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 완료 기준, 필수/추가 기능, 한계 및 비목표, 검증 방법, 사용한 AI 서비스와 모델 이름 포함 |

HTML 결과물은 없으며, 후속 미션(mission2-2)에서 `기획서.md`를 바탕으로 HTML을 제작합니다.

## 기획서 개요

| 항목 | 내용 |
|------|------|
| **대상 사용자** | Codyssey AI 네이티브 과정 수강생 |
| **사용 목적** | Codyssey 웹사이트, GitHub, Discord, ChatGPT/Gemini/Claude 등 여러 사이트를 한곳에 모아 수강생의 편의를 도모 |
| **화면 구성과 동작** | 상단 Title 표시, 기본 6개 사이트 카드 표시, 카드 클릭 시 새 탭으로 이동, 이메일 카드, 커스텀 사이트 추가/삭제, localStorage 저장, 모바일/데스크탑 반응형 |
| **필수 기능 (P0/P1)** | Title 표시, 기본 6개 카드 표시, 카드 클릭 시 새 탭 이동, 이메일 카드, 커스텀 사이트 추가, 새로고침 후 유지, 단일 HTML 파일 동작, 반응형 레이아웃 |
| **추가 기능 (P2)** | 기기 구분 기능, Title 7회 클릭 이스터 에그 |
| **한계 및 비목표** | 자동 로그인 기능, 코디세이 캘린더-구글 캘린더 연동, 데스크탑 좌석 위치 표시 |
| **검증 방법** | HTML 파일을 더블클릭해 열고, 서버/로그인 없이 페이지와 Title, 6개 카드가 표시되는지 확인 (TC-01) |
| **사용한 AI** | (기획서 작성 시 기록) |

## 실행 방법

HTML 파일이 없으므로 브라우저로 열 수 있는 결과물은 없습니다.

1. `기획서.md`를 마크다운 뷰어 또는 에디터로 엽니다.
2. 기획서 내용을 검토하고, 후속 미션(mission2-2)에서 HTML 구현 시 참고합니다.

## 제출 파일

| 제출할 파일 | 내용 |
|-------------|------|
| `기획서.md` | 기본 항목 5개, 필수/추가 기능, 한계 및 비목표, 검증 방법, 사용한 AI 서비스와 모델 이름 |

## 참고

- 제출물은 기획서.md 파일 1개로 한정합니다. HTML 구현은 후속 미션에서 진행합니다.
- 로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 포함하지 않는 것을 권장합니다.
- 사진·글·글꼴·라이브러리 등 외부 자료를 활용할 계획이라면 '필요한 자료'에 출처와 사용 권한을 명시합니다. 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입합니다.
