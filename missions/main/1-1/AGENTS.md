# 과제 지시사항


## 과제 목표
- 간단한 기계학습 관련 알고리즘 데이터 시각화 페이지 구현하기
- 언어는 python, 버전은 3.12
- 사용 데이터는 scikit-learn 패키지 안에 있는 iris 데이터
- 해당 데이터의 기본 체크 구현
- PCA 등으로 4개 feature중 어느 feature가 변별력이 높은지 시각화


## 요구사항
- ./REQUIREMENTS.md 내용을 따를 것
  - 이때, 3개 AI모델을 비교해야하는데, 무료로 사용가능한 ChatGPT, Claude, Gemini 로 하고 세부모델은 각 서비스별로 사이트 접속당시 사용가능한 무료모델로 정할 것
- 각 모델 접근은 OpenCLI brower extension을 사용할 것
