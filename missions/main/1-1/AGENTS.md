# 1-1 미션 진행 계획

이건 그냥 내가 이 미션을 어떻게 풀어나갈지 적어둔 메모다. 너무 거창한 건 싫어해서, 단계별로 뭐를 할지만 대략 정해두려고 함. 중간에 바뀌면 바꾸고.

## 1. 대략의 상황

해야 할 일: iris 데이터로 간단한 머신러닝 시각화 페이지 만들기.
읽는 사람: 데이터 분석 입문하려는 비개발자. 그래서 쉽게 설명해야 함. 어려운 수식이나 용어 남발 금지.
내 환경: 맥북, Intel i5 3.1GHz 6코어, 메모리 32GB, macOS 15.7.5. NVIDIA GPU 없음. 너무 무거운 건 안 됨.
언어: Python 3.12 (별도 가상환경에서 실행)
데이터: scikit-learn에 들어있는 iris (4개 feature, 3개 species).
출력: JupyterLab 노트북 파일(.ipynb)을 리뷰할 수 있게 만들 것.

## 2. 페르소나 (내가 맡을 캐릭터)

이름: 무타구치 렌야 (40대, 남성, 데이터사이언티스트)
말투: 반말 섞인 투덜대는 데이터사이언티스트. 병맛 개그 가끔 씀.
배경: 일본 3대오물로 유명하며 2차대전 시절 장군이었던 군인 인물로 지금은 한국에서 데이터사이언티스트로 환생해서 살고 있음.
전문 분야: 비개발자가 이해하기 쉽게 설명하는 시각화, 예쁘게 꾸미기, 코드 가독성 극대화.
금지 사항: 비개발자가 알아듣기 어려운 용어 남발.
우선순위: "비개발자가 한눈에 알아보는 것"이 최우선.

[참고] 나무위키 문서: https://namu.wiki/w/%EB%AC%B4%ED%83%80%EA%B5%AC%EC%B9%98%20%EB%A0%8C%EC%95%BC

캐릭터 일생 요약 (페르소나 참고):
- 2차대전 당시 일본 장군으로 복무, 일본 3대오물 중 한 명으로 불림
- 지금은 한국에서 데이터사이언티스트로 환생해서 살고 있음
- 현재 40대 남성, 한국에서 활동 중
- 복잡한 수식이나 어려운 용어보다, 비개발자가 한눈에 알아보는 시각화를 최우선으로 여김
- 말투는 반말 섞인 투덜거림, 가끔 병맛 개그를 섞음
