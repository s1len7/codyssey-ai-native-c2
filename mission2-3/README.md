# codyssey-ai-native-c2-mission2-3

# Codyssey Landing Page 테스트·개선

코디세이(Codyssey) AI 네이티브 과정 미션 2-3의 결과물입니다. 미션 2-2에서 선택한 HTML 페이지를 직접 테스트하고, 발견한 문제를 AI에게 설명해 하나씩 수정합니다. 다른 사람 1명의 사용 과정과 피드백을 확인하여 개선에 반영하고, 마지막으로 기획서와 제작검증기록을 최종 HTML에 맞게 정리합니다.

## 미션 취지

제작자는 이미 페이지 구조를 알고 있어 처음 사용하는 사람이 겪을 어려움을 놓치기 쉽습니다. 실제 사용 과정을 관찰하면 개선해야 할 부분을 구체적으로 확인할 수 있습니다. 발견한 문제를 AI에게 전달할 때도 '계산이 이상하다'보다는 어떤 값을 입력했고, 어떤 결과를 예상했으며, 실제로 무엇이 표시되었는지 관찰한 내용을 설명해야 합니다. 수정한 뒤에는 같은 테스트를 반복하여 문제가 해결되었는지 확인하고, 기존 기능에도 영향을 주지 않았는지 함께 점검합니다. 수정할 때마다 버전을 나누어 저장하면 변경 전후를 비교할 수 있습니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `페이지_v1_A.html` | 수정 전 버전 (원본) |
| `페이지_v2_A.html` | 수정 전 버전 (v1 → v2) |
| `페이지_v3_A.html` | 기기 종류 표시 기능 추가 버전 |
| `페이지_v4_A.html` | macOS 단 shortcut 표시 기능을 반영한 최종 HTML 파일 |
| `기획서.md` | 최종 HTML에 맞게 수정한 기획서 |
| `제작검증기록.md` | 두 AI 비교 기록, 테스트 4건, 수정 기록 4건, 사용자 1명의 피드백과 반영 결과 |

HTML 파일은 단일 파일로 CSS와 JavaScript를 포함하며, 외부 파일·로그인·서버 없이 브라우저에서 열 수 있습니다.

## 미션 수행 개요

| 단계 | 내용 |
|------|------|
| 1단계 | 선택한 HTML(` 페이지_v1_A.html`)을 테스트하여 문제 발견 |
| 2단계 | 발견한 문제를 AI에게 설명해 하나씩 수정 (버전별 저장) |
| 3단계 | 다른 사람 1명의 사용 과정과 피드백 확인 |
| 4단계 | 피드백을 페이지에 반영하고 결과 기록 |
| 5단계 | 기획서와 제작검증기록을 최종 HTML에 맞게 정리 |

## 제출 파일

| 제출할 파일 | 내용 |
|-------------|------|
| `페이지_v4_A.html` | macOS 단 shortcut 표시 기능을 반영한 최종 HTML 파일 |
| `기획서.md` | 최종 HTML에 맞게 수정한 기획서 |
| `제작검증기록.md` | 이전 미션의 두 AI 비교 기록과 테스트 4건, 수정 기록 4건, 사용자 1명의 피드백과 반영 결과 |

## 실행 방법

`페이지_v4_A.html`을 더블클릭해 브라우저로 엽니다. 외부 파일·로그인·서버 없이 단일 HTML 파일로 동작합니다.

## 참고

- HTML은 파일 1개로 구성되며, CSS와 JavaScript는 같은 파일에 포함되어 있습니다.
- 로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 포함하지 않습니다.
- 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입합니다.
- 수정할 때마다 버전을 나누어 저장하여 변경 전후를 비교할 수 있습니다.
