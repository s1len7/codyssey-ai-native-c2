# Codyssey Landing Page

## 대상 사용자
- Codyssey AI 네이티브 과정 수강생

## 사용 목적
- Codyssey 프로그램은 Codyssey 웹사이트, Github, Discord, ChatGPT/Gemini/Claude 등 여러 사이트 혹은 서비스 앱의 사용을 요구한다.
- 본 랜딩 사이트의 목적은 이러한 여러 사이트를 한곳에 모아 수강생의 편의를 도모하는 것이다.

## 핵심 사용자 시나리오

- US-01 (첫 방문): 수강생이 공유받은 HTML 파일을 연다 → Title과 6개 카드가 보인다 → Github 카드를 클릭해 새 탭에서 Github로 이동한다.
- US-02 (수업 중 이동): ChatGPT 카드를 터치해 새 탭에서 ChatGPT를 연다. 기존 랜딩 페이지 탭은 유지된다.
- US-03 (커스텀 추가): `사이트 추가` 버튼을 누르고 이름 `Notion`, URL `notion.so`를 입력한다 → 카드가 추가된다 → 새로고침해도 카드가 유지된다.
- US-04 (문의): 이메일 카드를 클릭해 운영진(`qna@innoaca.kr`) 메일 작성 화면이 열린다.
- US-05 (모바일): 아이폰에서 파일을 열어 카드가 1~2열로 정렬되고 터치로 이동된다.
- US-06 (잘못된 입력): URL을 비우거나 `javascript:` 같은 위험한 값을 입력하면 저장되지 않고 안내 문구가 표시된다.

## 화면 구성과 동작

- [P0] 화면 상단에 `Codyssey Landing Page` Title을 표시한다.
- [P0] 기본 카드 6개(Codyssey, Github, Discord, ChatGPT, Gemini, Claude)를 아이콘 + 서비스명 형태로 표시한다. 카드 전체 영역이 클릭/터치 대상이다.
- [P0] 카드 클릭/터치 시 해당 URL을 새 탭으로 연다. (현재 탭 유지)
- [P1] 이메일 카드를 표시하고 클릭 시 `mailto:qna@innoaca.kr`로 연결한다.
- [P1] `사이트 추가` 버튼과 입력 폼(이름, URL)을 제공한다.
  - URL에 스킴이 없으면 `https://`를 자동으로 붙인다.
  - `javascript:`, `data:` 등 위험한 스킴은 거부한다.
  - 이름은 최대 20자, URL은 중복 저장을 막는다.
- [P1] 추가한 사이트는 `localStorage`에 저장해 새로고침 후에도 유지한다.
- [P1] 추가 카드에는 삭제 수단을 제공한다. (권장: 삭제 미제공 시 잘못 추가한 사이트를 되돌릴 수 없음)
- [P1] 모바일에서는 카드가 세로/2열로 재배치되고 가로 스크롤이 발생하지 않는다.

## 제약 조건
- HTML은 파일 1개로 구성한다. CSS와 필요한 JavaScript를 같은 파일에 포함하고, 평가자가 브라우저에서 열어 기획서의 필수 기능을 확인할 수 있도록 한다.
- 로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 추가 기능으로 분류하고, 이번 제작 요청에서는 제외한다.
- 사진·글·글꼴·라이브러리 등 외부 자료는 사용 권한을 확인한 뒤 활용한다. 
  - 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입한다. 
  - 인터넷 주소로 불러오는 자료는 별도로 첨부하지 않으며, 다른 컴퓨터에서도 정상적으로 표시되는지 테스트한다.
