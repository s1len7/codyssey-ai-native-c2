# codyssey-ai-native-c2-mission2-2

# Codyssey Landing Page 제작·검증

코디씨(Codyssey) AI 네이티브 과정 미션 2-2의 결과물입니다. 미션 2-1에서 작성한 기획서를 두 AI(ChatGPT, Gemini)에게 동일하게 전달해 각각 HTML 페이지를 제작하고, 같은 방법으로 테스트한 뒤 하나를 선택해 제출합니다.

## 미션 취지

같은 기획서로 제작해도 AI마다 화면 구성과 기능 구현 방식이 달라질 수 있습니다. 두 결과를 같은 조건으로 테스트하고, 예상 결과와 실제 결과를 구분해 기록함으로써 AI 결과물의 장단점을 비교하고 선택 근거를 명확히 하는 과정을 실습합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `페이지_v3_A.html` | 두 AI 결과 중 선택한 HTML 파일 (ChatGPT 생성) |
| `제작검증기록.md` | 두 AI 서비스·모델 이름, 전달한 요청, 비교 내용, 선택 근거, 테스트 결과 3건 |
| `기획서.md` | 미션 2-1에서 작성한 기획서 (평가 참고 자료) |

HTML 파일은 단일 파일로 CSS와 JavaScript를 포함하며, 외부 파일·로그인·서버 없이 브라우저에서 열 수 있습니다.

## 두 AI 비교 결과

| 항목 | AI A (ChatGPT) | AI B (Gemini) |
|------|----------------|---------------|
| 사용한 AI 서비스·모델 | ChatGPT | Gemini |
| 대화 공유 링크 | https://chatgpt.com/share/6aeb2e9f-4420-83ec-ac99-96b28ff97648 | https://share.gemini.google/uuBbXjIJOmQN |
| 전달한 요청 | 기획서.md + 제작 요구사항 | 기획서.md + 제작 요구사항 |
| 화면 구성 | 다크 테마, 카드 애니메이션 | 라이트 테마, 심플한 디자인 |
| 기능 구현 | 필수 기능 모두 구현 + 추가 기능(기기 표시, 이스터 에그) | 필수 기능 모두 구현, 추가 기능 없음 |
| 선택 여부 | **선택** | 미선택 |

## 선택한 결과와 근거

**선택한 AI:** ChatGPT (AI A), `페이지_v3_A.html`

**선택 근거:** 기본 테스트 3건 결과 모두 만족하며, 기기 종류 표시와 제목 7회 클릭 이스터 에그 같은 추가 기능도 마음에 들어 ChatGPT 결과물을 최종 선택했습니다.

## 두 HTML 테스트 결과 비교 (3건)

| 번호 | 테스트 내용 | AI A (ChatGPT) 결과 | AI B (Gemini) 결과 |
|---|---|---|---|
| 1 | 기본 사이트 카드 6개를 차례로 클릭 | 6개 카드 모두 새 화면에서 대상 사이트로 연결됨 | 6개 카드 모두 새 화면에서 대상 사이트로 연결됨 |
| 2 | 자주 쓰는 사이트 추가 후 페이지 새로고침 | 추가한 사이트가 그대로 유지됨 | 추가한 사이트가 그대로 유지됨 |
| 3 | 작은 화면(400px 이하)에서 카드 클릭 | 카드가 2열로 정리, 화면이 잘리지 않고 클릭 가능 | 카드가 세로로 정리, 화면이 잘리지 않고 클릭 가능 |

## 실행 방법

`페이지_v3_A.html`을 더블클릭해 브라우저로 엽니다. 외부 파일·로그인·서버 없이 단일 HTML 파일로 동작합니다.
