# codyssey-ai-native-c2-mission2-2

# Codyssey Landing Page 제작·검증

코디세이(Codyssey) AI 네이티브 과정 미션 2-2의 결과물입니다. 미션 2-1에서 작성한 기획서를 두 AI(ChatGPT, Gemini)에게 동일하게 전달해 각각 HTML 페이지를 제작하고, 같은 방법으로 테스트한 뒤 하나를 선택해 제출합니다.

## 미션 취지

같은 기획서로 제작해도 AI마다 화면 구성과 기능 구현 방식이 달라질 수 있습니다. 두 결과를 같은 조건으로 테스트하고, 예상 결과와 실제 결과를 구분해 기록함으로써 AI 결과물의 장단점을 비교하고 선택 근거를 명확히 하는 과정을 실습합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `페이지_v1.html` | 두 AI 결과 중 선택한 HTML 파일 (최종 제출본) |
| `제작검증기록.md` | 두 AI 서비스·모델 이름, 전달한 요청, 비교 내용, 선택 근거, 테스트 결과 3건 |
| `기획서.md` | 미션 2-1에서 작성한 기획서 (평가 참고 자료, mission2-1 폴더 참조) |

HTML 파일은 단일 파일로 CSS와 JavaScript를 포함하며, 외부 파일·로그인·서버 없이 브라우저에서 열 수 있습니다.

## 선택한 HTML의 테스트 결과 3건

| 테스트 내용 | 예상 결과 | 실제 결과 |
|-------------|-----------|-----------|
| 테스트 1 (기본 기능) | | |
| 테스트 2 (기본 기능) | | |
| 테스트 3 (좁은 화면·빈 입력·인쇄 등 조건 변경) | | |

1건 이상은 조건 변경(좁은 화면, 빈 입력값, 인쇄 등)으로 테스트합니다. 예상과 다른 결과도 관찰한 대로 기록합니다.

## 실행 방법

`페이지_v1.html`을 더블클릭해 브라우저로 엽니다. 외부 파일·로그인·서버 없이 단일 HTML 파일로 동작합니다.

## 제출 파일

| 제출할 파일 | 내용 |
|-------------|------|

## 참고

- 선택하지 않은 HTML의 결과는 제작검증기록.md에 설명이나 화면 캡처로 남기고, HTML 파일 자체는 제출하지 않습니다.
- 로그인, API 키, 서버가 필요한 기능과 챗봇·AI 기능은 제외합니다.
- 사진은 로컬 파일 대신 https://로 시작하는 인터넷 주소로 삽입합니다.
