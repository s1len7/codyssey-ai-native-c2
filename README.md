# codyssey-ai-native-c2

코디세이(Codyssey) AI 네이티브 과정 미션 수행 결과물을 모아 둔 저장소입니다.

각 미션 폴더(`missionX-Y`) 안에는 기획서, HTML 결과물, 제작/검증 기록 등이 들어 있으며, 모든 결과물은 로그인·서버·API 키 없이 브라우저에서 단일 HTML 파일로 바로 열 수 있습니다.

|------|------|------|-----------|

## 파일 구성

| 경로 | 설명 |
|------|------|
| `backup/` | 미션 안내 문서와 샘플(zip, 코랩 세션 리포트 등) |
| `missionX-Y/` | 각 미션의 결과물(기획서, HTML, 기록 등) |
| `README.md` | 이 문서 |

## 실행 방법

모든 HTML 결과물은 단일 파일로 동작하며, 외부 파일·로그인·서버 없이 브라우저에서 열 수 있습니다.

1. 원하는 미션 폴더로 이동합니다.
2. 해당 폴더의 `.html` 파일을 더블클릭하거나 브라우저로 엽니다.
3. 예: `mission1-1\영화_A_초안.html`, `mission2-2\페이지_v1.html`

인터넷 연결이 필요한 파일(예: 외부 CDN 사용 시)은 인터넷 환경에서만 꾸밈이 정상적으로 표시됩니다.

## 미션별 기록 파일

| 파일 | 용도 |
|------|------|
| `기획서.md` | 누가 쓰나 / 무엇을 하려고 / 화면과 동작 / 필요한 자료 / 완성 기준 |
| `미션X_기록.md` | AI 대화, 오류 재현, 수정 내용, 테스트 결과 |
| `제작검증기록.md` | 두 AI 비교, 테스트 항목, 수정 기록, 사용자 테스트 |
| `피드백.md` | 동료에게 보낼 피드백 내용 |

## 공통 규칙

- 모든 결과물은 HTML 한 장으로 완결되며, 로그인·서버·API 키가 필요하지 않습니다.
- 수정된 HTML 파일은 원본(`…수정전.html`, `…원본.html`)을 덮어쓰지 않고 보관합니다.
- 기획서와 제작 기록은 미션 제출 시 함께 제출 대상입니다.

## 참고

- `backup/` 폴더에는 미션 안내 문서와 샘플(zip 파일, 코랩 세션 리포트)가 들어 있습니다. 실제 제출 결과물은 각 `missionX-Y/` 폴더의 파일을 기준으로 합니다.
